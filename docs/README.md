DOCUMENTACIÓN
=============

DOCUMENTOS DE REFERENCIA
------------------------

- project-status: estado completo del proyecto — qué está hecho, qué falta, roadmap de implementación
- architecture: arquitectura del sistema, capas, patrones
- architecture-visual: diagramas visuales de la arquitectura
- data-model: modelo de datos, entidades y relaciones
- data-flow-map: mapa de flujo de datos entre capas
- flujos-resumen: los 21 flujos de la app con flechas y su estado, de un vistazo
- flows: flujos de negocio principales (aplicación, contratos, pagos)
- manual-convivencia: manual de convivencia (MC-001): publicación, aceptación, bloqueo de aprobación, pasos por rol y datos de prueba
- manual-convivencia-fuente: texto completo del manual tal como llegó en el PDF, con sus pendientes en project-status
- components: inventario de componentes React
- component-connectivity: conectividad entre componentes
- conventions-patterns-cheatsheet: convenciones de código y patrones
- api: documentación de API routes y server actions
- cron-payments: generación mensual de pagos y cron externo
- getting-started-dev: guía de inicio para desarrollo
